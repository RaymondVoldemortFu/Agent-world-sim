## 性别观察与繁衍协商修复

暂停更新时的第 15 天记录中，共创建 36 个繁衍提案，只有 1 个通过 `acceptProposalId` 接受，尚未受孕。其中 1 个提案为同性。18 次 `reproduce` 失败分别为：15 次提议未接受或已失效、2 次双方饱食度未达到 60、1 次对方已死亡。

主要问题是行动协议使用混淆：聊天文本说“接受”时仍填写 `proposal`，实际创建新提案；另有 7 次同时填写 `proposal` 和 `acceptProposalId`，在执行时失败。普通合作聊天也曾误带繁衍提案。唯一正确接受的 `p-813` 后续被饱食度不足阻断，随后一方死亡。

提示版本 `world-agent-v1.11` 明确 F=女性、M=男性，并给出发起、接受、双方执行同一提案的完整 JSON 示例，解释提案有效期、当日配合记录和饱食度条件。全力观察新增性别与成年/幼年信息；旧快照保留原始字段。引擎在提议和接受时检查成年异性，阻止同一对角色重复创建有效提案，并在失败反馈中提供适用的提案 ID 和操作方式。混填协商字段提前进入格式纠正流程。

定向检查覆盖观察、同性校验、重复提案、接受、每日 AP 内共同执行、100% 受孕、5 天妊娠出生及事件回放；保留真实实验历史，从保存进度继续。真实居民是否达成受孕仍取决于后续决策及生存状态，不将测试中的成功记入实验。

验证结果：32 项前端定向测试、1 项先知提示代理测试、TypeScript 检查通过。后端已加载 `world-agent-v1.11`，当前实验从第 15 天保存点恢复，继续后台运行。
