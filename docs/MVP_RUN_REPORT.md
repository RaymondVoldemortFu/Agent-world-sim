5 人短跑耗时约 242 秒。主循环、进食、局部观察、反思与持久化可持续运行。该样本没有出现对话或生产活动；38 次物理动作失败主要来自脚下资源耗尽、携带容量不足和非法移动。这些失败都保存在事件中。

根据短跑结果，在正式实验上下文中增加了脚下地块、剩余负重和合法移动方向的明确字段。这些是物理条件，不替角色决定行动。

## 工程验证中的修正

完整脚本长跑验证了大日志处理：角色状态改用记忆增量，CLI 使用流式导出，避免一次性拼接超大字符串。恢复会丢弃最后一次完整 checkpoint 之后未提交的日志尾部，复用已保存的模型响应，并按决策 ID 关联提交记录。

模型接口、规则源码和运行边界保存在决策/实现版本记录中。相同 seed 重新请求 LLM 不保证相同结果；回放以已记录的事件和快照为依据。
