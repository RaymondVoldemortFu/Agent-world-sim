# 自动观察与大声说话实验

规则版本 `mvp-1.3.0`，提示版本 `world-agent-v1.4`，动作 schema `action-v2`。

## 规则

- 每次决策自动获得最新周围九宫格的地块与居民信息，不消耗 AP、不单独请求模型，也不产生观察事件。移除重复的 `look` 动作。
- 普通说话 `chat` 仍消耗 1 AP，周围九宫格可听见。
- 大声说话 `shout{text}` 消耗 2 AP，以横纵坐标差的最大值计算距离，两格内（含斜向）的所有活人可听见。只广播文本，繁衍协商仍由 `chat` 完成。
- 听闻记忆保留说话者、事件编号与来源；听到两格外圈的声音不会获得对方的私有信息或扩大视觉范围。事件计入对话统计，纪事可按“大声说话”检索。
- 剩余 AP 不足 2 时动作失败，按统一非法动作规则扣 1 AP。每日 4 AP，可用于两次大声说话。幼年适用相同费用。
- 两格内听众与说话者串行决策；三格外仍可并行。已有移动观察边界覆盖声音半径。
- 保留 20×20 地图、20 位初始居民、seed `20260909`、腐败食物饱食度 +20 / 生命 -20、免费成功丢弃、3 天保鲜、平原食物上限 4 / 恢复等待 5 天、成功交配必定受孕 / 5 天妊娠。

## 验证与实验

45 项单元测试、5 项后端测试、13 项常规浏览器测试和生产构建通过（另有 2 项可选测试跳过）。浏览器验证配置页、喊话导入检索与刷新持久化。测试覆盖自动观察的零副作用、移动后视野更新、横向及斜向听闻边界、死亡角色排除、记忆来源、幼年及 AP 不足、整日两次大声说话、并行观察一致性与精确回放。

新版脚本基线完成 100 天：10 人存活、0 次物理动作失败；6,976 个事件、21 个快照和 6,876 份决策观察全部校验一致，最终 hash `8471d982`。这验证生存与存储流程，交流机制由定向测试验证。

前一轮 `llm-pressure-ap4` 在完成第 17 天后按用户追加规则暂停，11 人存活；1,353 个事件、4 个快照和 1,336 份决策观察验证一致。历史记录保留，规则未混用，详情见 [AP4 实验记录](AP4_RUN_REPORT.md)。
