# 4 AP 与腐败食物营养实验

规则版本 `mvp-1.2.0`，提示版本 `world-agent-v1.3`。

## 运行配置

- 20×20 地图，20 位初始居民，seed `20260909`，目标 100 天。
- 每位居民（含幼年）每日 4 AP。成功丢弃物品消耗 0 AP，并继续当前普通行动机会；非法丢弃消耗 1 AP。
- 每份腐败食物生命 -20、饱食度 +20；饱食度最多 100，生命最低 0。进食和喂食使用同一规则。恢复量可在新建配置中调整。
- 食物保存 3 天，转移保留到期日。未改造平原食物最多 4 份，采后 5 天开始恢复，每天 1 份。
- 成功交配必定受孕，妊娠 5 天。
- 模型 `deepseek-v4-flash`，关闭 thinking，最多 6 并发。

本轮独立保存至 `artifacts/llm-pressure-ap4/`；[打开实验](http://127.0.0.1:5173/?experiment=llm-pressure-ap4)。上一轮 `mvp-1.1.0` 记录继续保留，其配置页展示当时的规则。

## 验证

40 项单元测试通过，覆盖腐败食物恢复与伤害、饱食度上限、喂食、免费丢弃后仍有 4 次普通行动、决策 ID 唯一性、远处预取结果复用和回放。5 项后端测试、12 项常规浏览器测试与生产构建通过；浏览器测试验证免费丢弃后仍有 4 次普通行动、并行预取响应只请求一次及刷新恢复。

脚本实验 `scripted-pressure-ap4` 完成 100 天，10 人存活、0 次物理动作失败；6,976 个事件、21 个快照及 6,876 份决策观察校验一致，最终 hash `422e2781`。脚本结果用于验证工程机制。
