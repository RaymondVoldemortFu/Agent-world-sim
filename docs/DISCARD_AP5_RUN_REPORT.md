# 丢弃、放置与每日 5 AP

- `drop {item, quantity}`：直接销毁背包物品，成功时 0 AP，随后继续当前行动机会。不会生成地面物品；销毁食物时同步删除相应批次，优先最早到期。
- `place {item, quantity}`：消耗 1 AP，把背包物品放到脚下地面，其他人可以捡取。食物保留原到期日。
- `take {item, quantity}`：消耗 1 AP，从脚下地面捡入背包。
- 默认每日 5 AP，成年与幼年相同。数量超出背包库存时销毁与放置均失败，仍按非法动作规则消耗 1 AP。

提示词明确区分背包物品、地面物品和未采集资源。配置页和纪事区分“丢弃”与“放置”。原有死亡掉落保持为把随身物品留在死亡地块。

55 项单元测试、5 项后端测试、13 项常规浏览器测试及生产构建通过。浏览器验证一次免费销毁后两位居民仍各有 5 次普通行动，共 11 次模型请求，每次只请求一次，12 个事件包含日末；刷新和暂停恢复一致。
