# 64k 上下文、移动自主权与初始村落

## 上下文窗口

服务默认和本地 `.env` 的 `AGENT_CONTEXT_WINDOW` 均为 **65,536 tokens**。决策预留 600 tokens，累计输入估算超过 `(65536 − 600) × 0.9 ≈ 58,442` 时尝试压缩，为新观察、压缩摘要和输出留余量。估算沿用 UTF-8 字节数 / 2 的保守算法，真实用量仍按模型账单记录。

新实验设置提供“下次实验上下文窗口（tokens）”，默认 65,536，可填 4,000–262,144 的整数。该值保存为 `world.config.contextWindow`，通过观察的 policy 传到后端，优先于服务默认值；数据库保存、导出及续跑均沿用它。旧实验缺少该字段时回退到服务默认。修改新实验草稿不修改当前实验。

活动历史继续增量追加。固定规则、人格、已掌握知识目录保留；外部长期记忆、原始工艺查询与会话祖先关系延续现有实现。全局费用、token 和每日调用准入预算保持原配置；窗口扩大不代表每次填满窗口。配置页展示实验实际窗口；旧档未保存时使用后端默认值。

## Agent 对规则移动的控制

模型输出增加独立的 `movement` 字段，可与目标、说话一起提交，省略时维持已有设置：

```json
{
  "intent": "守在这里等同伴回来，之后采食仍回到出发地",
  "movement": { "stayMinutes": 600, "returnAfterGather": true },
  "speech": { "channel": "public_speak", "text": "我今天留在这里，你们可以回来找我。" }
}
```

- `stayMinutes`：从当前时刻起累计的劳动分钟，范围 0–18,000。默认 5 AP 时每天 600 分钟；设置 600 相当于一个劳动日，可跨日。0 立即解除。到期自然恢复移动。
- 停留期间禁止规则移动和跨区，包括觅食、寻人和运料；战斗策略要求的紧急撤退优先；仍可在本格进食、饮水、采集、生产、交流和自卫。本人可以再次调用模型解除约束。本地缺粮导致规则等待时仍允许模型按预算重新思考。
- `returnAfterGather`：日常外出采食／取水成功后，是否带回出发地；false 表示不自动返程。返程不以“已下达采集动作”判定，而以真实动作成功完成判定。路径使用已有陆路／桥梁／船只规则，返程同样耗费移动时间。停留中的返程保留，到期可继续。
- 建筑或制造所需的物料运输仍返回指定工地；这是生产目标自身的物流要求。若希望只采原料而不运回，使用新增 `gather` 目标。

```json
{
  "intent": "采两公斤燧石，留在采集地等交换",
  "movement": { "stayMinutes": 0, "returnAfterGather": false },
  "goal": { "skill": "gather", "item": "flint", "quantity": 2, "expires": 5 }
}
```

`quantity` 是目标背包存量（kg），默认 2 kg；可以填写 x/y/region 约定采集地点。达到目标后按返程设置结束，所需物品必须是实际存在且可采的原料。若选择返程，原点是收到本次目标时的位置；途中改目标会清除旧目标的采办行程。饱食和负重等生存约束继续有效。

移动约束、起点与返程阶段进入 Agent 的 brain 状态、事件回放及增量上下文。人物详情显示剩余停留时间、是否返程和当前返程状态。

## 初始村落

在“开始新实验 → 生态开局”选择 **初始村落**，内部 ID 为 `ecoPreset: "village"`。该开局将出生分布设为 `compact`：全部居民在河谷的连续 2×2 陆地上集中居住。原有采集者和农业定居开局继续可选。

村落是进入初始快照的有限资产：

| 资产 | 数量／算法 | 20 人示例 |
| --- | --- | --- |
| 农田 | 0.35 ha / 人，分布在四格 | 7 ha，共四块 |
| 食用储粮 | 人数 × 45 天 × 2500 kcal ÷ 3400 kcal/kg | 661.76 kg 谷物 |
| 下一季种粮 | 农田面积 × 120 kg/ha | 840 kg 谷物 |
| 住宅 | 按各格居民数选择 6 人泥屋或 15 人共居屋 | 四栋泥屋，24 床位 |
| 粮仓／工棚／炉灶／水井 | 每格各一处，已完工 | 各四处 |
| 共有工具 | 每格一套完整锄、镰、石片、手斧、磨盘及一块空白木板 | 四套，放在工棚 |
| 羊群 | max(2, ceil(人数 / 3)) | 七只，其中四只雌性 |
| 草料 | 羊数 × 1.5 kg × 30 天 | 315 kg，放在畜圈 |

谷物进入真实粮仓库存，种粮与口粮具有相同物理属性，居民仍需自行协商保留播种用粮；不会由系统强制冻结种粮。原始坚果口粮另行保留。初始居民掌握农耕和基础农具加工知识，知道本村位置及公共设施；默认日常采食后返回出发地，后续可自行改变。

田地占用土地并相应减少初始化野生存量。春谷按年内第 100 天、秋播谷按第 285 天的播种历史估算积温，过去气温按相同种子重建并乘 0.85 水分系数。开局在生长期时提供在田作物；尚未播种或该茬已经结束时提供待播农田。季节系统随后按正常规则推进，作物仍需要照管、收割和下季播种。

按当前春谷目录，每人 0.35 ha、毛产 750 kg/ha，在 8% 损失和 65% 基础照管系数下约产 157 kg/人/年，约合 214 个口粮日；照管充分时约 328 日。这是潜在单茬产量，实际还受水分、肥力、损耗及劳动制约，村落仍需其他食源、牧养或扩大耕作。

水井复用正常建筑条件：完工且状况大于 40% 时，每口每日回补 200 L 至本格水源容量上限。所有新建井也采用相同规则；不把村落初始水井当作特殊永久资源。

## 验证

- 前端定向测试覆盖停留跨日到期、主动取消、原地采食、危险时停留、跨区拦截、成功／失败采集、返程切换、旧目标替换和事件回放。
- 初始村落覆盖 1／20／60 人、五个季节日期、固定种子重现，核对土地、住房、物料、仓容和世界不变量。
- 后端测试验证旧长度的历史在 64k 下继续追加，接近新上限才压缩，并保留已有压缩重试及长期记忆校验。
- `village-movement-3day-smoke`：3 天 / 20 人脚本试跑完成，20 人存活、0 动作失败、0 模型调用；846 条事件、4 个快照通过 MySQL 回放一致性校验。该试跑验证初始化、规则和存储，不评估模型自主选择或长期社会发展。
- 构建通过；前端 52 项、后端 24 项定向测试通过；浏览器 3 项测试通过，包含新开局选择、集中出生配置、人物移动约束及服务实际窗口展示。


## 坐标导航

LLM 可下达 `{"goal":{"skill":"navigate","x":5,"y":6,"expires":10}}`，指定当前区域内的目的地和截止日期。规则逐格执行，无需每一步调用 LLM。

导航采用 BFS，寻找步数最少的上下左右可通行路线，使用个人记住的地形与当前观察；未知地块先视为可通行，观察后重新规划。水域需舟筏或完工桥梁，并绕开当前可见野兽的一格攻击范围；已在危险范围内时允许向外脱离。该路线最小化步数，移动耗时仍由坡度、负重、道路决定（平地空载6分钟，120分钟为1AP）。

导航优先于采集、返程和孤单寻人，下达时解除旧定点停留；途中可就地处理危急饮食。实际到达终点后结束目标，恢复日常规则。不可达时向模型反馈阻断原因，可修改目的地。紧急撤退成功后保留目的地，重新规划；战斗中的撤退仍使用血量决定的成功率。角色详情和模型上下文显示导航状态。

## 开局告示与十日深度反思

新建 village 初始村落时，在村落左上格放置一块完工告示板，初始铭文为“野兽非常危险！！需要武器！！”，作者为原住民。居民同格可读；通过现有 inscribe 目标刻写的新板材优先存入同格告示板，保留历史文字。仍需空白板材和刻字工具，刻写耗时沿用现有规则。铭文页面可查看内容和位置。

村落中放置三具原住民遗体，以独立的 ecology.relicCorpses 保存在初始快照中，地图与角色观察均可看到。它们不增加初始人口或实验死亡统计。开局布置只应用于新建的初始村落实验。

生态 Agent 在世界第10、20、30……天的首次可用模型机会进行深度反思，仍遵守实验总预算和个人每日调用／token准入阈值。预算或服务不足时顺延；只有通过格式校验的反思才标记本周期完成，不重复补跑已错过的周期。

反思复用追加式上下文和外部记忆检索，在本次观察尾部添加任务，保持共享前缀。要求回顾近期生存、安全、生产合作、人际关系和承诺履行，并规划未来十天；以 reflection.summary 和 reflection.plan 输出结论（各最多800字），同时通过现有目标、移动、战斗策略字段落实行动。摘要与计划写入人物状态、高重要度个人记忆及后端外部记忆，人物详情可查，事件补丁可回放。

仅 deep_reflection 请求启用 thinking.type=enabled；普通决策和压缩保持关闭。默认64k窗口预留最多8192输出token（含思考预算），小窗口相应缩减；供应商超时240秒，客户端超时300秒。思考过程不作为公开日志保存，使用供应商实际usage计费。反思不额外扣AP，随后执行的具体动作照常扣除AP。
