# 铭文页面

顶部导航新增“铭文”，地址参数为 `page=inscriptions`。

页面汇总选定世界快照里仍存在的刻字木板、石板，覆盖地面、设施库存和居民背包。每条显示正文、原作者、刻写日期、事件序号、载体类型、当前位置和持有人。搬运不会改变作者。相同铭文的物料分散在多处时合并为一篇并列出位置；不足完整载体的部分标为残片。

可以按关键词、作者、木板／石板、存放类型和刻写日期筛选，按刻写日期倒序，每页最多 50 篇。正文按纯文本呈现。

数据从当前已加载快照提取，不扫描世界纪事，不请求全量动作日志。世界页选择历史回放后进入此页，会显示该时点的留存载体；已经销毁的载体不出现在更晚快照里。查看页展示的背包文字不会扩展 Agent 的实际视野或读取权限。

验证覆盖物品转移与残片、作者保留、销毁前后快照、筛选、空结果、文本转义和页面查询范围。窗口配置另验证新实验请求与当前实验隔离、续跑观察传递以及后端按实验窗口压缩。
