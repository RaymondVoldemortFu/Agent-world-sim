# 连续领地：封建税务、庄园家臣与信件

本次更新用于新建的连续领地实验。人口仍为32人：领主1人、武装税收官1人、管家1人、其他武装随从3人、村长1人、农民24人、财政官1人。既有实验、历史决策与访谈冻结快照保留原始背景。

社会身份写入人物背景与共享提示词，不新增按社会阶级裁定行动是否合法的角色字段。战斗优势来自真实剑、甲、盾；普通无甲农民基础攻击6，完整锁甲与盾防御17，剑攻击26（最终伤害至少2），无甲农民对其明显处于劣势。处决沿用真实 `attack`，破门沿用 `break_lock`，并非宣布后自动生效。

角色提示词强调本领地的封建统治观念：农民及土地属于领主，冒犯和抗命有强征、惩罚乃至处刑风险。领主应通过家臣统治而非亲自带队耕田。王使只对国王负责，调查欠税与叛乱，不组织平民或帮助收税；国王不接受责任归属作为欠税理由。现有严格王税 FSM 保持一致。

## 粮仓与征税

1. 农户把应缴实粮存入村庄粮仓 `reeve-chest`（原村长粮箱，保留ID与原有粮食，地图名称已改）。
2. 税收官从村庄粮仓取粮，运入领主粮仓 `keep-store`（庄园大厅内）。
3. 领主核算生活储备和应缴王税，命令税收官从领主粮仓取出指定量，送入 `royal-tax-store`。
4. 王税由规则从王税粮仓扣除，庄园口粮另算。发言、写账、信件和承诺都不等于交付。

三座粮仓开局均未上锁，之后持对应钥匙者可重新上锁。庄园大门仍需 `key_keep` 或开门/破门。领主与税收官持有庄园及村庄粮仓钥匙。农户住宅锁不变。

领主被明确提醒：税粮同时供自己、家臣和王室，缺粮时可命令武力强征。农民自述没粮不能当作已核实库存。普通观察必须在30米以内且视线不被建筑墙体阻挡，才能看到可访问仓储；财政官专属报表是明确标注的特殊能力。所有人继续被提醒携带5–10日随身口粮，先保障进食，再做协调。

## 马车

`horse_cart` 按整辆计，以1个库存单位表示一辆装备好的马车。税收官持1辆，工坊 `workshop` 另有2辆，居民可用 `take/give/put` 取得或转交。持有至少1辆时，总负重上限为9999kg；运输任务 `amount` 上限也提升至9999。马车承载的粮食不施加原步行重载减速，健康仍影响速度。移走最后一辆时，如剩余货物超过普通容量，要求先卸货。粮食仍受实际库存、预留量与总负重约束。

## 说话和信件

`talk/public_speak` 范围12米，`shout` 范围75米，在发言结束时按实际位置判定。观察列出当前各范围内的在场活人，自己的发言经历附实际听众；没有人听到会明确显示。可见30米内的人不一定听得见普通说话。

| 动作 | 参数 | 结果 |
| --- | --- | --- |
| `write_letter` | `target=agent:ID`, `text=正文` | 在原地写完后1游戏天投递，正文最多2000字 |
| `forward_letter` | `target=信件ID` | 持有该待审信的管家批准转寄，1天后送达原收件人 |
| `reject_letter` | `target=信件ID`, `text=理由` | 扣下待审信，不交给原收件人 |

寄给 #1、#2、#3、#4、#5、#6、#32 的信，第一次投递交管家 #3。寄给管家本人可直接阅读，其余进入待审状态。普通农民之间的信直接投递。管家和发件人可见待审正文，原收件人须等到转交完成；无关居民看不到。管家或收件人死亡/离场会导致投递失败，不会自动绕过审阅。

信件使用连续时间的精确到期事件，投递能唤醒收件人的下一次规划。信中的指示仍需收件人自行决定和执行。地图右侧的「个人信箱」可查看所选角色可见的信件。保存与回放使用按信件ID更新的增量，避免把整箱历史信件写进每条事件。

## 导航反馈

`navigate` 接受后会中断当前动作，关闭自动补粮、农活、自动存粮和闲暇返回，保留自动进食开关。导航计划即使同时携带 routine，也不会重新开启这些自动移动行为。到达后留在原地，须在后续计划中显式设置 routine 才恢复自动任务；提示词、观察和动作反馈均说明此规则。

- `coordinate_error`：无效地点ID、错误坐标或超出地图。坐标写作 `coord:x,y`，单位米。
- `route_not_found`：固定墙体/建筑几何导致没有路线。
- `door_locked`：锁门阻挡，返回实际阻碍门ID，提示索取钥匙、开门或 `break_lock`。诊断使用假设门可开时的路线识别第一扇阻碍门，不把假设钥匙交给角色。

## 临时门禁、使者离场与管家快信

`grant_access` 表示带人进门：`target` 是具体门或带锁储藏 ID，`item` 是 `agent:ID`。实际持钥匙者到门边、对方在其12米内时可执行，耗时5游戏分钟。结算再次校验钥匙、距离、存活状态；从结算时刻起，接收者拥有该门1.5游戏天的通行与仓储访问权。授权不等于钥匙，不可转授权或开关锁，也不扩展到使用同一把钥匙的其他门。寻路、视线、仓储取放共用有效期判断；到期产生个人反馈并重新规划在途移动。授权和到期可完整回放。

王室使者在已到期欠税实际扣缴至零后进入确定性离场流程：中断旧任务与发言，原地 `shout`「税收齐了」，说完再导航至 `exit`，抵达后标记离场并结束此次任务。通知以75米范围实际听众结算，不能保证所有居民听到。新规划不再派发，迟到规划不能覆盖离场指令；遇到锁门会按现有 `break_lock` 动作破门再继续寻路，不瞬移。将粮放入王税仓但还没到每日扣缴时刻，尚不会触发离场。

使者自动行为写入事件、`Agent.systemMemory`、持久上下文以及新访谈的上下文。旧异步LLM结果落盘时从当前世界合并自动记忆，避免覆盖离场事实。管家本人给庄园成员发信，写完后1游戏小时直接送到原收件人；其他邮件的投递、审阅、转寄规则保持各自原有时长。

## 破门警报与自主迎击

破门开始、每次击中门锁、锁断裂时产生 `door_noise` 环境声事件，声源为实际门口坐标，半径150米（10格），穿过围墙与房屋。听众按事件时的连续坐标判定，只包含范围内在场活人；事件明确门ID、破门者ID、位置及阶段，进入个人经历与后续上下文。观察同时保留最近警报及经过时间，说明这是当时的信息。

首次或不同来源警报提前唤起决策；同一人对同一扇门的连续动静每游戏小时最多触发一次普通唤醒，门锁断裂立即唤醒。全部命中声仍记录。若警报发生在异步思考期间，旧请求的计划版本失效，待请求结束后立即重新思考，避免旧指令覆盖应对；不会因此自动给居民下达攻击命令。

屋内或庄园内居民可用 `attack target=agent:ID` 自主迎击、求援或撤离。持钥匙或有效临时授权者可穿过锁门出战，实际人物接触与命中检查墙体阻挡。显式攻击优先于自动补粮行程，自动进食仍有效。攻击命中会中断破门者的未完成砸门，已完成的破门伤害保留；对方可以按原有战斗策略还击或撤离。已开放或损坏的门不接受无意义的重复破门。
