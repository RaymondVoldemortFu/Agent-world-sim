# 尸体、全力观察与 5 AP 实验

规则版本 `mvp-1.6.0`，提示版本 `world-agent-v1.7`，动作 schema `action-v4`。

## 本轮规则

- 默认每位居民每日 5 AP，包含幼年。
- `drop` 成功时免费，直接销毁背包物品；`place` 消耗 1 AP，把物品留在脚下地面，食物保留到期日。
- 死亡后在死亡地块保留尸体，随身物品掉在地面。尸体持续存在，地图以灰色叉号表示，地块详情可查看死者。
- 日常自动观察仍为九宫格，消耗 0 AP；`corpses` 单独列出可见尸体，`people` 只包含活人。尸体不能回应或缓解说话者孤单。
- `survey {}` 全力观察消耗 2 AP，观察切比雪夫距离 3 格内的环境（含斜向，内部最多 7×7 个地块，边界处裁剪）。幼年同样可以使用，AP 不足时失败。
- 结果是动作提交时的私有快照，包含地块资源、地面物品、新鲜/腐败食物、农田、棚屋、可见活人和尸体，以及日期、事件编号、观察中心。该结果记录在 `lastSurvey`，不会随远处世界实时更新。重新观察会替换上一份结果。
- 全力观察不向模型提供他人私有背包、记忆、孤单值或隐藏配方。当前视野与历史观察在提示词中明确区分。
- 尸体位置和观察快照都进入事件、快照及导出文件。旧世界继续按历史记录展示，可回放。

孤单机制、2 AP 大声说话、20×20 地图、20 位初始居民、腐败食物饱食度 +20 / 生命 -20、平原食物上限 4 / 5 天恢复、3 天保鲜、成功交配必定受孕 / 5 天妊娠继续保留。孤单细节见 [孤单规则](LONELINESS_RUN_REPORT.md)。

## 调度与请求

全力观察在动作提交时采样并冻结，不扩大之后决策的实时视野。两格内的互动依赖继续串行，三格外可并行；测试覆盖前一位远处角色死亡后，后一位预取决策仍有效、观察结果在提交时包含尸体。

普通模型输入保留 24,000 字符上限；携带三格观察快照的输入上限为 40,000 字符，以容纳密集场景。超过上限仍在本地代理被拒绝。工作记忆仍按原规则裁剪。

## 验证与运行

63 项单元测试、6 项后端测试、14 项常规浏览器测试和生产构建通过（2 项可选浏览器测试跳过；新回放测试修正异步筛选等待后单独重跑通过）。尸体标记、地块详情、全力观察结果与历史回放已在界面中检查。新增覆盖四种死亡原因的尸体、死者不能交流、2 AP 费用、三格含斜向与地图边界、私有信息隔离、快照冻结、并行提交时采样、密集观察大小限制和精确回放。

脚本基线 `scripted-survey-ap5` 完成 100 天，0 次无效动作；第 24 天全部死亡，最终保留 20 具尸体。该脚本只处理生存、不交流，用于工程验证。2,367 个事件、21 个快照、2,267 份决策观察全部校验一致，hash `53f483d4`。

前一轮 `llm-loneliness` 在完成第 16 天后因用户追加规则暂停：6 人存活、116 次说话、4 次赠予或喂食；1,121 个事件、4 个快照、1,105 份决策观察全部校验一致，hash `d13819ed`。原始记录保留。
