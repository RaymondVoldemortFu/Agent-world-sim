# 孤单机制与物品位置区分

规则版本 `mvp-1.4.0`，提示版本 `world-agent-v1.5`，动作 schema `action-v2`。

## 规则细化

`self.inventory` 是手上/背包中的物品，`self.food` 是背包食物批次；`currentTile.ground` 与 `groundFood` 是脚下地上的物品与食物。地上的东西尚未拿在手中，不能直接 `drop`。必须先 `take`，确认新观察中的背包库存后才能丢弃；自然资源 `resources` 则通过 `gather` 进入背包。提示词明确区分这三处来源。

每位居民有自己的孤单值、最近有效说话日期和抑郁状态。初始孤单为 0，新生儿从出生日起独立计时。

| 参数 | 本版取值 |
| --- | --- |
| 孤单条长度 | `round(100 − 60 × 外向性)`，外向性 0–1，上限 40–100；越外向越短 |
| 增长时机 | 连续两天没向人说话，从第二天日末开始每日 +20，上限封顶 |
| 缓解 | 每次对至少一名活着的听众成功 `chat` 或 `shout`，说话者孤单 −20，最低 0，并重置未说话计时 |
| 有效交流 | 普通说话半径 1，大声说话半径 2；仅听闻、自言自语和失败动作不计 |
| 抑郁 | 孤单满条时进入；孤单降到非零时仍持续，只有清零才解除 |
| 抑郁伤害 | 日末额外扣 10 生命，当天刚满条也生效，可能致死；原有饥饿与休养回血仍独立结算 |

例如第 1 天有效说话后，第 2 天没说话不会增长，第 3 天仍未说话时日末 +20。进入抑郁后若孤单为 40，一次说话降至 20 仍会承受抑郁伤害，第二次降至 0 才解除。

居民详情显示孤单条的当前值和性格上限；列表标注抑郁状态，配置页显示计算规则。模型每次观察能看到自己的状态，但不会获得其他居民的私有孤单数据。日末记忆记录抑郁伤害，死亡原因、物品掉落与回放同步保存。

保留每日 4 AP、成功丢弃免费、自动观察、2 AP 大声说话、腐败食物饱食度 +20 / 生命 -20、20×20 地图、平原食物 4 份 / 5 天恢复、3 天保鲜及 100% 成功交配受孕 / 5 天妊娠。

## 验证

52 项单元测试、5 项后端测试、13 项常规浏览器测试及生产构建通过（2 项可选浏览器测试跳过）。界面已检查孤单条、性格上限、抑郁提示及移动端布局。覆盖增长边界、个性上限、满条状态持续、清零解除、说话计时重置、活人听众、幼年出生计时、私有状态边界、抑郁死亡和物品掉落、精确回放，以及地面物品不能直接丢弃。

纯生存脚本基线 `scripted-loneliness` 完成 100 天，0 次无效动作，最终无人存活。该脚本不会说话，用于验证社会压力与存储机制，不代表真实模型行为。2,156 个事件、21 个快照、2,056 份决策观察全部校验一致，hash `79d2bffa`。

前一轮 `llm-auto-observe-shout` 按用户追加规则在完成第 10 天后暂停；20 人存活、5 次对话、2 次赠予或喂食。1,012 个事件、3 个快照、1,002 份决策观察全部校验一致，hash `ba298cb2`。该轮不作为完整 100 天结果，保留历史文件。
