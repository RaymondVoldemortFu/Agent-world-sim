## 复查命令

安装 Gitleaks 后，可在仓库根目录复查历史；使用 `--redact=100` 避免打印命中值：

```sh
gitleaks git . --log-opts='--all --reflog --full-history' \
  --ignore-gitleaks-allow --redact=100
```

工作区检查应使用 `git ls-files --cached --others --exclude-standard` 枚举的文件镜像；直接扫描整个目录会把有意保留在本地的 `.env` 和运行产物一并纳入。
