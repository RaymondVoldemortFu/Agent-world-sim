# 兽患、防御产业与铭文

生态实验新增可移动的野兽实体、动态聚居地识别、武器防具、四级围墙和实物铭文。模型继续决定生产、集结、防守与公共约定，规则引擎执行战斗、移动、制造与材料消耗。

## 野兽与聚居地

聚居地按每个有人或有建设的地块及其一格邻域识别：至少 5 位活着的居民，或者至少 3 处有效基础设施。基础设施包括完工且状况高于 20% 的建筑，以及面积大于零、已完成清理的农田。附近重复中心会合并；人口离散、死亡或设施损毁会使聚居地重新划分。

| 参数 | 默认值 |
| --- | --- |
| 初始袭扰兽 | 有聚居地的区域尝试生成一只／群 |
| 初始荒野兽 | 每区尝试生成一只／群，无人区也生成 |
| 聚居地袭扰兽刷新 | 距所有聚居地至少 3 格，且距其中一个不超过 5 格 |
| 居民出生保护距离 | 任何新野兽距活人至少 3 格 |
| 地形限制 | 陆地，无建筑或农田，不与已有野兽贴近 |
| 活兽上限 | 每区 3 只／群 |
| 补充周期 | 每 5 天每区最多补充一只／群，有合适地块且未达上限才生成 |
| 移动 | 每天最多一格，沿陆路逼近聚居地或三格内居民；荒野兽平时游荡 |
| 生命 | 180–260 |
| 基础攻击 | 24–36，每轮再乘 0.9–1.1 的波动系数 |
| 恢复 | 每日恢复 12 生命，上限为该野兽满血值 |
| 日末遭遇 | 每只野兽最多结算 3 轮战斗；刚生成当日不行动 |

种类为熊、巨型野猪、狼群。狼群是一个战斗实体。野兽不会穿水或瞬移；人和动物碰面后的主动迎战可在日间发生，逐日袭扰在当日居民动作结算后发生。

野兽活动独立生成 `wildlife` 事件，包含移动、交战、围墙受损、掠食和破坏；主动迎战生成 `fight_beast` 事件。兽群状态、死亡、掉落及居民记忆均进入 MySQL 增量回放。死亡野兽在当前状态中保留 30 天，历史事件继续保留。

袭扰会损坏未受围墙保护的聚居地建筑、作物，消耗部分存粮，或杀死一头畜兽。生成密度是可控的游戏压力模型，尚未与食物网的动物出生率绑定。新实验可在 UI 关闭“野兽与聚居地袭击”进行对照。

## 战斗数值

成年人的徒手对兽攻击为 6。每轮在野兽一格内的成年居民共同自卫，野兽反击一个附近居民；双方同轮出手，最后一击也会受到反击。幼年可被袭击，但不参与自动攻击。主动 `fight_beast` 消耗 120 分钟；同一遭遇中的邻近成年人防御反应不额外扣 AP，装备仍磨损。

无装备、无围墙、满血单人面对最弱野兽：需要 `ceil(180/6)=30` 次命中，而每次反击至少 `ceil(24×0.9)=22` 点，最多承受 5 次即死亡。自然日末恢复仅 3 点，野兽恢复 12 点，不能靠一次徒手攻击与长时间休息磨死它。受伤野兽的最后一击、城墙支援等属于不同场景。

六位徒手成年人每轮初始合计 36 点伤害，能击败最弱野兽，但可能减员。测试同时覆盖独行、群体、防具和最强个体；装备不保证所有情况下都能单挑成功。

| 随身武器 | 对兽攻击 |
| --- | ---: |
| 徒手 | 6 |
| 手斧 | 10 |
| 硬木棍 | 12 |
| 柄装石斧 | 16 |
| 石矛 | 22 |
| 青铜斧 | 24 |
| 弓箭组、铁斧 | 28 |
| 青铜矛 | 34 |
| 铁矛 | 40 |

生皮护具减伤 12%，皮甲 25%，青铜札甲 42%，木皮盾 18%。护甲与盾相乘结算剩余伤害，不直接相加；皮甲加盾减伤 `1−.75×.82=38.5%`。仅最强武器、最强护甲和一个可兼容的盾生效；弓占双手，不与盾叠加。完整单位重量与耐久都要有效，地面物品和物品碎片不会算作已装备。

新生产链包括硬木棍、青铜矛、铁矛、生皮护具、皮甲、青铜札甲和木皮盾，复用石片、皮革、骨针、绳索、金属、铸造与锻炉工艺。武器、防具随战斗磨损，可沿原有修理接口维修。对人的攻击保留原有最低 20 点基准，高级武器和防具参与结算。

每次击败兽群掉落鲜肉 12 kg、生皮 4 kg、骨 3 kg、脂 1 kg，均留在地面。忽略初始兽群，即便持续清空三个区域，每五天最多补充三只，肉食刷新上限约为 11,520 kcal/天，相当于 4.6 名成年人日需；实际还需战斗、搬运、储藏并承担伤亡。它不能无成本供养整个 20 人聚落。

## 四级围墙

围墙是占用土地、消耗实物和多人劳动的建筑。用 `goal.skill=build`、`recipe` 填下面的 ID 建造；需要相应知识。高级围墙可独立建设，当前以新建更高等级替代防御主力，不会自动把旧墙变成新墙。

| ID / 等级 | 材料 kg | 劳动 分钟 | 满耐久 |
| --- | --- | ---: | ---: |
| `palisade` 一级木栅墙 | 木 240、绳 8、石 40 | 3,600 | 180 |
| `earth_wall` 二级夯土围墙 | 黏土 600、石 180、木 60、水 100 | 8,400 | 420 |
| `stone_wall` 三级干砌石墙 | 石 1,200、木 60、绳 4 | 15,600 | 850 |
| `fortified_wall` 四级加固石墙 | 石 1,800、铁 20、木 160、绳 8 | 26,400 | 1,400 |

这些建筑抽象为地块中营地核心的围护单元，材料不是围满 250×250 米地块周长的工程预算。防御范围按同格结算。地图画出等级边框，详情显示真实耐久。

完工且耐久大于零的墙先承受对同格居民的兽袭以及聚居地掠夺；墙被打穿后的剩余伤害才传给居民，再由护甲减免。单次命中只选择最高等级有效墙，不累加全部城墙。未完成工程、已经攻破的墙不会保护人；围墙不会保护相邻格居民。

维修复用建筑修缮：每次最多恢复 5% 状况，消耗相同比例的原建筑材料及一次劳动。围墙也会按各自建筑衰减率自然损耗。石墙的资源和劳动需求要求持续供料，而不是临战瞬间生成护盾。

## 木板、石板与公共记述

新材料为 `wood_tablet` 空白木板、`stone_tablet` 空白石板，刻写后成为 `inscribed_wood`、`inscribed_stone`。空白木板用 1.2 kg 木料加工成 1 kg 板，需切削工具、60 分钟；石板用 2.5 kg 石料加工成 2 kg 板，需锤击工具、120 分钟。工序中余量计为碎屑。

模型接口：

```json
{"intent":"把讨论结果留下来供后来的人阅读","goal":{"skill":"inscribe","item":"wood_tablet","text":"本轮守夜由甲乙负责，粮仓分配方式仍待大家确认。","expires":10}}
```

规则会准备板材与工具。木板刻字耗 60 分钟，石板耗 120 分钟；两者需切削工具，石板另需锤击工具。一次使用一整块空白板，内容最多 240 字，完成后放到脚下地面，并结束本次刻字目标。

铭文随批次保存唯一 ID、作者 ID、作者姓名、刻写日期、事件边界和原文。搬运、转移、死亡掉落和序列化保留这些字段；修改约定可写另一块板，现有铭文不会被原地无痕覆写。物品可以被拿走或销毁，长久保存取决于载体是否仍在世界里。

同格居民会免费阅读新铭文并形成重要的亲历记录，进入该格的后来者也会阅读。读过的 ID 用于去重；其他人的背包不提供公开阅读，自己的背包、同格地面及可用设施中的铭文可以阅读。观察上下文展示最近最多 12 篇可及铭文，完整实物与已经读取的长期经历继续存储。

铭文记录的是作者所写的内容，不自动证明“全体同意”，不会建立强制产权，也不会代替繁衍同意。界面明确显示作者和日期，模型提示将铭文作为有来源的数据处理。事件类型 `inscribe` 可检索，阅读经历同样进入个体经历查询。

## 先知与模型认知

先知外向性固定为 0.85，其余四维保留种子生成的差异。新生世界直接保存该值；旧生态实验继续决策时以固定外向性观察，并在下一次行动提交时写回状态，历史回放不改写。

开启野兽的生态世界中，所有居民的共享固定提示都包含野兽危险常识：野外有危险野兽、会袭击聚居地、单人徒手无法战胜，以及结伴、装备和围墙的防御作用。具体位置仍须观察或听闻；关闭野兽时不注入这段常识。先知身份提示保留 User 创世信息与围墙、铭文知识。先知开局掌握新工艺目录。普通角色看到当前视野内的野兽及有效随身装备；夜间记忆只通知亲眼看到的居民。

高层目标新增 `defend`（item 为可见野兽 ID，也可给出集结位置）与 `inscribe`。生存规则在没有明确防御目标时倾向于避开孤身遭遇，有足够成年同伴时共同自卫。协商分工、生产哪些装备和建墙目标由模型决定。城墙和配方的原始定义仍受上下文知识保护，铭文不会进入共享 system。

战斗可能影响发起者两格外的共同防御者，因此有邻近野兽时，空间调度把有关请求的冲突范围扩展到五格，避免其他模型依据已过时的防御者状态决策。

## 自主战斗策略

模型可独立设置 `combatPolicy`，省略表示保持已有选择：

- `{"mode":"flee"}`：遇战即尝试撤退，也是未设置策略的新旧生态居民的默认行为。
- `{"mode":"low_hp","retreatHp":60}`：生命不高于阈值时撤退。阈值可取 1–100，省略默认 60。
- `{"mode":"fight"}`：坚持作战，不主动撤退。

共享提示词、人物上下文和详情展示有效策略。自动兽战在每轮伤害前、受伤后检查；受到其他居民攻击时也执行目标自己的撤退策略。致命伤不会先被撤销，因此应选择足够高的撤退阈值。

紧急撤退沿陆路寻找两步内、不在任何当前同区域活兽及本次攻击者攻击范围内的落点；不会越过水域或野兽占据的格子。没有这样的路线时仍可能受伤或死亡。撤退作为战斗反应不额外扣 AP，夜间 AP 已耗尽仍能触发。

脱身会解除定点停留，取消尚未完成的原地动作、普通目标及采办／返程计划；坐标导航目标保留，脱身后重新规划。已经投入的 AP 不返还。本人及原位置附近目击者获得带危险地点的经历，之后由模型决定告警、求援或再集结。规则不会强制生成一次对话。

空间调度同步考虑撤退改变的位置：生态普通交互冲突半径为三格，有邻近野兽的交互扩展为五格，避免其他角色使用撤退前的预取观察。历史事件继续按原补丁回放，不重算过去战斗。

撤退改为概率判定：有安全陆路时，成功率 `0.10 + 0.80 × clamp(hp, 0, 100) / 100`；满血90%、60血58%、20血26%。使用世界种子随机数，结果随事件补丁保存并可重放。每轮每人最多尝试一次：攻击前失败不会在受伤后重复掷骰，生命首次降到阈值则可在受伤后尝试。失败留在原地继续本轮战斗；无安全路线必定失败。人物详情展示当前成功率，失败原因写入事件及个人经历。

### 死亡刷新冷却与战斗力倍率

新实验可在UI设置 `beastRespawnDays`（0–365天，默认10）和 `beastPowerMultiplier`（0.1–5，默认1）。同区域任何野兽被击败后，在死亡日加冷却天数之前暂停该区域全部新野兽刷新；冷却结束后按原每5天的检查节奏补充，不会直接复活原个体。其他区域与已存活野兽继续活动。死亡记录至少保留至冷却结束，避免长冷却被30天清理提前截断。

倍率对新生成野兽的最大／当前生命、攻击进行等比例缩放（整数四舍五入，至少1），每日回血同样缩放；0.5代表减半。生成位置、随机序列和刷新数量规则不变。UI配置针对下一次实验，已有存档中的生命和攻击不会重写。
