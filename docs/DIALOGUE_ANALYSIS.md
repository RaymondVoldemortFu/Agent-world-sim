# 轻量对话分析

入口：顶部“对话分析”，URL `?experiment=实验名&page=dialogue`。支持后台实验和本地导入存档。

## 方法选择

第一版用固定词组规则进行多标签意图和主题识别，并用字符 TF-IDF 向量做相似表达检索。所有计算在浏览器 Web Worker 内运行，不调用 LLM，不下载模型权重，不需要 Python 分词或向量数据库。规则与词表在 `frontend/src/analysis/dialogue.ts`，版本为 `dialogue-rules-1`。

意图包含请求、协作、提供、知识传授、状态通报、询问、同意、拒绝、争执和关怀；主题包含食物饮水、工具加工、农业、建筑仓储、地点搬运、健康情绪、繁衍与分配规范。无匹配时保留“未分类”。肯定类词组对局部否定做简单抑制。规则结果保留命中词组，供用户对照原文。

TF-IDF 特征是中文连续双字片段与英文词，权重为 `(1 + log(tf)) × (1 + log((N+1)/(df+1)))`，再做 L2 归一化；用倒排表计算余弦相似度。每次载入以整份已载入对话拟合 IDF，筛选时保持同一套向量。相似表达限定在当前筛选内，排除自身，展示得分至少 0.15 的前五条。0.15 是展示阈值，得分不是意图置信度，也不代表语义等价。

此方案便于核对、增加规则和观察误差。没有人工标注训练集，因此不报告分类准确率。多义词、隐喻、复杂否定、指代和上下文省略可能造成误判；谈到“配方”或“合作”并不证明角色已经传授知识或履行合作。

## 统计口径与图表

只提取成功发生的 `chat` / `shout` 事件，跳过动作开始、失败和记忆副本，并按事件序号去重。默认排除没有其他人听见的发言，也可取消勾选查看全部成功发言。

一个事件可有多个意图和主题，分类柱状图的总和可能超过发言数。趋势图包含全部发言、协作、传授和争执的每日次数，日期间隙补零。

热力图纵轴为发言者、横轴为实际听众。听众来自事件 `recipients`，去重并排除发言者本人。一次广播可贡献多个格子的计数；它描述声音传播，不代表一对一交谈、信任或指定对象。不会从话中的姓名推断听众。点击格子可筛选该有向关系。

支持日期、参与 Agent（说过或听到）、意图、主题、关键词和渠道筛选。原文每页 60 条，可以查看规则依据、相似措辞和关联行动决策。

## 性能与边界

后台数据复用世界纪事的精简 SQLite 索引，按 chat/shout 类型分别游标分页，每次最多 200 条；不下载世界补丁。首次分析读取指定已提交边界内的所有对话，页面展示载入数量。页面固定该边界，手动“刷新分析”才重新载入；实验每三秒刷新不会重复触发全量分析。

本地导入从 IndexedDB 读取对应边界的对话，立即剥离补丁。统计、过滤、TF-IDF 和相似检索都在 Worker 中执行，离开页面终止 Worker。筛选与翻页复用内存语料，不重复请求日志。内存与索引大小随对话条数和字词数增长；当前不为大规模跨实验语料提供持久化向量索引。

## 验证

规则案例覆盖多标签、简单否定、原文保留及未知类别；统计检查覆盖听众去重、自环排除、范围和关系筛选、失败动作排除；向量检查覆盖相同文本、自身排除和无匹配。

浏览器检查覆盖跨后端分页读取、过滤、相似表达、热力图、日期校验、无匹配状态、手机宽度和本地导入，并确认分析过程没有模型请求。实际实验页面的载入时间、请求数及脚本错误记录在 `artifacts/dialogue-browser-benchmark.json`。

## 本机页面实测

2026-09-10，实验 `eco-hybrid-v2-100day-20` 的事件边界 #42201：载入 1,097 条成功发言，其中 1,097 条有其他听众；读取 7 页精简事件，从打开页面到结果可见为 6,211 ms，浏览器脚本错误为 0。这是单次端到端样本，包含开发服务器模块加载、网络、分类、向量构建与渲染，不是纯分类耗时或延迟分位数。筛选、翻页和相似检索的无重复日志请求行为另由浏览器测试验证。
