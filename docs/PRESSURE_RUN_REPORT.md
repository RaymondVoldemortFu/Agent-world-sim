# 20×20 资源压力实验

更新于 2026-09-10。规则版本 `mvp-1.1.0`，模型提示版本 `world-agent-v1.2`。

## 本轮规则

| 参数 | 本轮值 |
| --- | --- |
| 地图 / 初始人数 / 实验天数 | 20×20 / 20 / 100 |
| Seed | 20260909 |
| 未改造平原野生食物上限 | 每格 4 份 |
| 平原食物恢复 | 最后一次采集后 5 天开始，每天 1 份，最多 4 份 |
| 食物保鲜期 | 3 天，包含采集、农田收获和初始配给 |
| 食用腐败食物 | 每份生命 -20、饱食度 +0，可以致死 |
| 成功交配受孕率 / 妊娠期 | 100% / 5 天 |
| 农田 | 每日产 3 份，待收上限 12 份，每次收获最多 4 份 |
| 模型 / 并发上限 | deepseek-v4-flash，关闭 thinking / 6 |

第 1 天取得的食物在第 4 天腐败。第 1 天采过的平原在第 5 天日末结算时开始补回 1 份，即第 6 天行动时可采；再次采集会重新计时。丘陵保留原有 3 份上限及恢复规则。

食物有独立的批次到期日期。进食、喂食优先使用新鲜且最早到期的批次；选择数量超过新鲜库存时，超出部分使用腐败食物并扣血。转赠、丢弃、拾取、死亡掉落都保留原来的日期，转移时优先使用最早到期批次。腐败食物仍占空间；地块野生资源和农田待收作物在收取前不计腐败。

共同繁衍本身没有随机受孕失败；本轮将 100% 明示为固定配置。仍需双方协商接受、成年异性、同格、饱食度至少 60，并在同一天分别行动。母亲在妊娠期内死亡会终止妊娠，出生后冷却 10 天。

## UI 与记录

顶部新增「配置」页面，按当前世界实际存档展示地图、资源、繁衍和预算；新建设置支持修改地图边长、食物容量、恢复等待、保鲜期及腐败伤害。库存和地面物品展示新鲜/腐败数量及到期日，首页食物储备按新鲜食物计数。

旧版实验保留原数据，仍可查看和回放。新规则运行到独立目录 `artifacts/llm-pressure-20x20/`，可打开 [本轮实验视图](http://127.0.0.1:5173/?experiment=llm-pressure-20x20)。

- 36 项单元测试通过，包括腐败时间边界、腐败伤害、转移/死亡掉落保持日期、容量失败原子性、平原恢复与重新计时、农田收获、繁衍必定受孕、并行观察一致性和精确回放。
- 5 项后端测试通过；类型检查和生产构建通过。
- 11 项常规浏览器测试通过，覆盖配置页桌面/移动端、新建、导入导出、检索、恢复、预算、互斥及并行提交；另执行旧版 100 天存档导入/回放测试并通过。
- `artifacts/scripted-pressure-20x20/` 完成 100 天，4 人存活、16 人死亡、0 次物理动作失败。3,588 个事件、21 个快照精确回放，最终 hash `a749c541`；3,488 份决策观察审计全部一致。该轮使用固定脚本决策，用于工程验证。
- 长跑暴露的记忆 ID 冲突已修复：每次事件内用独立序号标识通知，避免记忆窗口已满时多个死亡通知重复。增加了回放回归测试。

初始野生食物从上一轮 64×64 的 17,238 份降至本轮 1,251 份，减少约 92.7%。这个比较同时改变了地图面积、资源容量和时间规则，不能把后续行为变化单独归因于其中一个参数。

事件 #241（第 4 天）：桑 #18 向川 #6 发出繁衍提议，未获接受，也没有共同动作。事件 #919（第 27 天）：最后一位居民原 #5 食用腐败食物后死亡。

25 次进食包含腐败食物。130 次失败是库存食物已经为零时仍尝试丢弃食物；这反映出模型没有稳定依据实时库存修正行动。第 27 天全图仍有 1,239 份野生食物，有限视野、局部资源状态与无效决策同时影响了生存，不能仅用全图食物总量解释结果。

完整事件及 21 个快照回放通过，893 份决策观察审计全部一致。原始记录位于 `artifacts/llm-pressure-20x20/`；本轮结果保留用于比较。
