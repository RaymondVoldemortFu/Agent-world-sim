# 15×15 地图与先知实验

规则版本 `mvp-1.7.0`，提示版本 `world-agent-v1.8`，动作 schema `action-v4`。

## 初始配置

- 默认地图 15×15，共 225 个地块；20 位初始居民，seed `20260909`，目标 100 天。
- 20 人中有 1 位先知：初始居民 #1，保留随机姓名、性格与身体属性，开局掌握全部合成/建造配方。
- 当前全部配方为基础工具、高级工具、棚屋；先知的知识从统一配方表初始化，新增配方时会同步覆盖。
- 先知通过自身 `knownRecipes` 获得完整的材料、工法与工具要求，可以直接制作或建造，仍需收集所需材料并消耗 AP。初始物资与生命条件和其他居民相同。
- 附近居民可以看见“先知”身份并请教。说话传授具体方法，普通居民用实验亲自验证后掌握；配方不自动传给全体居民或子代。
- 界面居民列表与详情标注先知，配置页显示人数，详情列出已掌握配方。初始知识不计为本轮实验发现。

## 沿用规则

每日 5 AP；成功丢弃直接销毁背包物品且免费，放置到地面消耗 1 AP；自动观察九宫格，全力观察 2 AP / 三格；大声说话 2 AP / 两格。尸体保留在死亡地面，可被观察。孤单与抑郁规则、腐败食物饱食度 +20 / 生命 -20、3 天保鲜、平原食物最多 4 份 / 5 天恢复、成功交配必定受孕 / 5 天妊娠均沿用。

## 验证

67 项单元测试、6 项后端测试、15 项常规浏览器测试和生产构建通过（2 项可选浏览器测试跳过）。浏览器验证 15×15 默认地图、唯一先知标识、三条配方展示和刷新恢复。新增覆盖先知唯一性、完整配方初始化、材料与 AP 约束、制作两种工具及完成棚屋、向普通人传授后由实验验证、子代不自动继承、局部身份可见及回放一致性。

前一轮 `llm-survey-ap5` 的 20×20 实验在完成第 14 天后暂停，9 人存活。1,292 个事件、3 个快照和 1,278 份决策观察核验结果见其 `verification.json` 与 `context-audit.json`；历史实验不混用新配置。
